Dalam ekosistem pembangunan laman web moden, kelajuan bukan lagi sekadar kemewahan—ia adalah keperluan asas bagi pengalaman pengguna dan penarafan SEO.

Gabungan **GatsbyJS** sebagai penjana laman statik (*Static Site Generator*) dan **Tailwind CSS** sebagai kerangka penggayaan berasaskan utiliti memberikan sinergi yang luar biasa untuk membina projek digital seperti Belantara.

## Kelebihan Seni Bina Ini

### 1. Pra-Rendering HTML Tulen (Zero Server Overhead)
Gatsby membina setiap halaman menjadi fail HTML, CSS, dan JavaScript statik sebelum dihantar ke pelayan. Ini bermakna tiada lagi kueri pangkalan data yang perlahan atau kegagalan pelayan pangkalan data pada masa permintaan pelawat.

### 2. Pengoptimuman Imej Automatik dengan Gatsby Sharp
Imej selalunya menjadi punca utama laman web menjadi lambat. Plugin imej Gatsby secara pintar:
- Menjana pelbagai saiz resolusi untuk skrin mudah alih dan desktop.
- Menggunakan placeholder blur (*low-resolution blur-up*) semasa imej sebenar sedang dimuatkan.
- Mengelakkan anjakan susun atur (*Cumulative Layout Shift - CLS*) secara automatik.

### 3. Tailwind CSS Menghapuskan Kod Berlebihan (Purge & Tree-Shaking)
Tailwind CSS mengimbas semua fail kod komponen projek dan hanya menyertakan kelas utiliti yang benar-benar digunakan. Hasilnya, fail CSS yang dihantar kepada pelawat seringkali bersaiz kurang daripada 15KB!
